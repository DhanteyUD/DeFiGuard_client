# DeFiGuard

**AI-powered, multi-agent DeFi portfolio risk monitoring platform.** Real-time fraud detection and autonomous alerts across 13 blockchains — powered by ASI:One and SingularityNET MeTTa.

> Colosseum Cypherpunk Hackathon Winner | ASI Alliance Participant

---

## Features

- **AI Agent** — Multi-agent system monitoring DeFi portfolios 24/7 with MeTTa AI risk scoring, rug-pull detection, and autonomous real-time alerts across Solana + 12 EVM chains
- **Telegram Bot** (@DeFiGuard_Bot) — Instant risk & breach alerts, high-risk token warnings, on-demand portfolio checks, and natural language commands
- **Chrome Extension** — Real-time token scanning on DeFi sites with on-page risk indicators and scam detection

## Tech Stack

- **Next.js 15** (Turbopack) + **React 19** + **TypeScript**
- **Tailwind CSS 4** — Styling
- **Framer Motion** + **GSAP** — Animations
- **Lucide React** — Icons
- **Axios** — HTTP client
- **Next-PWA** — Progressive Web App support

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server with Turbopack |
| `npm run build` | Create production build |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |
